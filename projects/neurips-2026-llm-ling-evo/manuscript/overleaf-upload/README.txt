Overleaf upload instructions
============================

Upload this whole folder, including the figures/ subfolder, to a new Overleaf project.
Set main.tex as the main document and compile with pdfLaTeX.

Files:
- main.tex: conventional LaTeX manuscript using natbib/BibTeX.
- references.bib: BibTeX bibliography used by main.tex.
- figures/: figure assets used by main.tex.
- main-embedded-bibliography.tex: fallback version with references embedded as ordinary text. Use this only if BibTeX causes trouble; it still needs figures/.
