# Verified facts — repo infrastructure

One fact per bullet, each verified against the file cited. Update in place when a fact changes; delete when it stops being true.

- `claude-fable-5` is available on this repo's `ANTHROPIC_API_KEY` (probed 2026-07-03). Two API quirks: (1) it **rejects an explicit `temperature` parameter** (400: "temperature is deprecated for this model") — omit it, like Opus 4.7+ in `src/utils.py::_anthropic_supports_temperature` (Fable is NOT yet in that omit-list; add it before using Fable through `call_llm`); (2) it is a **reasoning model whose thinking blocks share `max_tokens`** — with `max_tokens=2048` a translation prompt returned only a `thinking` block, `stop_reason="max_tokens"`, zero text. Use `max_tokens` ≥ ~16000 for generation tasks and always check for empty text (see `scripts/phase9_fable_seeds.py::fable`).

- There is **no `.venv`** in this repo despite CLAUDE.md saying so — Python is provided by **pyenv 3.11.10** via `.python-version`, with all framework deps installed there (`python3` from the pyenv shim just works from repo root). Verified 2026-07-02 (`ls .venv` → absent; `python3 -c "import yaml, openai, dotenv"` → OK).
- `src/utils.py::call_llm()` returns a **dict** `{"content", "reasoning", "usage"}`, not a string — use `response["content"]` (see `src/agents.py:37`). Verified 2026-07-02.
- **Direct-Anthropic calls default to `max_tokens=1024`** (`src/utils.py::_call_anthropic`, env override `ANTHROPIC_MAX_TOKENS`). Verbose game analyses (esp. game-only 8-agent runs) can exceed this before emitting the JSON decision → truncated response → `Could not extract send` → run dies. Killed 2 runs on 2026-07-17/20. Now set to 4096 in `.env`/`.env.example`. The OpenRouter path has no such low default (`OPENROUTER_MAX_TOKENS` unset = provider default).
- **Myth exchange has a one-round diffusion lag in multi-agent runs**: the `{other_agent_myth}` an agent receives belongs to its **previous round's** game partner (`src/myth_writer.py::_get_paired_opponent_id` reads the round `turn-1` pairing), while this round's game is against a *different* partner (round-robin). So myths spread through the population lagged by one round, and a myth is never strategically informative about the current co-player. Same semantics in the June baseline and all memory-primary runs (verified 2026-07-20 against run data). Design decision still open: keep (post-interaction exchange, "gossip-like" diffusion) vs switch to current-partner myths (pre-play cultural signal).
- Under `LLM_PROVIDER=auto` (the default), `anthropic/*` model slugs route to the **direct Anthropic API**, not OpenRouter (`src/utils.py::DIRECT_MODEL_ALIASES` maps the slug to a native model id). When the Anthropic credit balance runs dry (hit 2026-07-17: 10/10 batch runs failed with 400 "credit balance is too low"), set **`LLM_PROVIDER=openrouter`** on the run command to route the same model through the funded OpenRouter key. Batch checkpoints resume across the provider switch. **Caveat (audit 2026-09-04):** the switch is not settings-neutral — the OpenRouter path sends `reasoning.effort=medium` by default, so Claude runs with extended thinking ON via OpenRouter and OFF direct. Same for `openai/*` (direct = `OPENAI_REASONING_EFFORT`, default `minimal`; OpenRouter = vendor default) and `google/*` (direct = `GEMINI_THINKING_LEVEL`; OpenRouter = effort medium). See `data/analysis/api_equivalence_audit_2026_09_04/`.
- **Gemini 3.6 Flash (`google/gemini-3.6-flash`, direct id `gemini-3.6-flash`) is the no-thinking Gemini arm.** Probed 2026-09-04 with `scripts/probe_gemini_settings.py` on the real round-1 investor prompt: `GEMINI_THINKING_LEVEL=minimal` → 0 thought tokens on 6/6 calls (low: 72–103; default medium: 234–321). 3.7 and 3.8 Flash only go down to `low` (Google thinking table). **Temperature is accepted but ignored** on 3.6 (5/5 distinct outputs at temperature 0), same as 3.7, so `src/utils.py::_gemini_supports_temperature` omits it for both and run metadata records `temperature_sent: false`. `GEMINI_API_KEY` is in `.env` since 2026-09-04, so `LLM_PROVIDER=auto` now routes `google/*` slugs direct on this machine too.
- `ms-pdf-extract` routes through **Gemini-3-flash via OpenRouter** (`model: openrouter:google/gemini-3-flash-preview`, `parallel_jobs: 6`), configured in `.claude/skills/ms-pdf-extract/config.local.yml` (untracked, gitignored via `.claude/skills/*/config.local.yml`). Reason: Sonnet returned truncated markdown on long PDFs; Gemini transcribes full papers incl. references (needed for leads). At the time the repo had `OPENROUTER_API_KEY` and Anthropic keys only, hence OpenRouter routing; a `GEMINI_API_KEY` was added 2026-09-04 but this skill still uses OpenRouter. (Verified 2026-07-02.)
