## Attribution

Audit all 44 previously selected clause-change events across the fixed 48-agent,
45-run sample. Keep their original semantic assessments and source reasons
explicitly labeled as inherited machine judgments, not newly human-validated
attributions. Add independently reproducible exact-phrase diagnostics comparing
each after-quote with previous own, all earlier own, actually exposed and matched
unseen texts. Normalize wrapper Myth: and punctuation/case for this diagnostic,
not raw evidence. Report longest consecutive token matches and novel five-word
sequences shared with each candidate source. These are lexical diagnostics,
not semantic classifiers or causal transmission estimates.

For every event record the preceding game context, whether the current game
precedes writing, and the first subsequent role-appropriate decision. Verify
final-file hashes, accepted own outputs, exposed texts in accepted myth prompts,
and exact quotation/source identities. Unseen myths must be from another run
and match the recorded design cell/composition; verify against their finals.
Also compute exposure-versus-unseen novel-five-word uptake for all 432 later
myths, preserving run clustering and reporting it as descriptive lexical evidence
only. This is complementary to existing word-uptake analyses, not a new norm test.

## Three bounded behavioral questions

1. Forgiveness after a shortfall: enumerate selected events that explicitly
   prescribe continued sending after poor return/noise. Require an unambiguous
   new/revised action, a prior personal sender outcome visible in retained
   messages, and a subsequent sender decision under that clause. Generic fog
   imagery alone is insufficient. Any operational definition of poor must be
   explicit; do not silently substitute below-half for a text's vague “poor.”
2. Repeated defection: enumerate selected reduced-sending clauses. Require a
   stated count, a measurable threshold, same-partner applicability and enough
   visible observations to meet it. “Season,” “greed,” “thin,” and “dry” are not
   assigned analyst-invented numerical definitions. Report ambiguities and
   censored/no-trigger opportunities, not behavioral failures.
3. Explicit sender amounts: screen six previously selected unconditional numeric
   or full-endowment formulations: T03 R6 (5), T07 R9 (5), T21 R4 (3), T24 R4 (3),
   T25 R3 (5), T36 R3 (5). Require textual endorsement, a first sender choice
   after writing and before the next own myth, and an earlier sender choice.
   Narrated/conditional amounts are excluded. For eligible cases report pre/post
   send, distance to target before/after, and whether the target behavior predates
   writing. No same-round game-before-myth action is a consequence of that myth.

The active window ends at the next myth because intervening writing can change
the instruction. Later actions may be listed as censored illustrations but not
silently included. Actual chosen sends are outcomes; communicated values and
saved messages determine what was observed, not hidden true peer actions.

Eligibility gate before aggregate outcome inference: at least 10 distinct runs
with clear eligible observations and sufficient within-family/order variation;
for a before/after conditional comparison, at least 5 runs in each relevant
state. These pragmatic thresholds are not a power calculation. If not met, do
not fit pooled regressions, p-values, or imply a null effect. Report descriptive
case checks only. Do not multiply the sample size by treating myths as replicas.
If a test passes, account for prior action, family and task order and resample
whole runs, grouping all agents from the same run. No predictive model will be
trained on this small selected-event dataset.

## Scope of completion

Completion means a complete ledger of the recorded events, source diagnostics,
explicit eligibility/exclusion decisions, and any defensible descriptive checks.
It does not mean an exhaustive new semantic census of 480 myths or satisfying
all tests by loosening definitions. Narrative names/rituals remain a separate
layer; existing human review is a sanity check, not established reliability.
