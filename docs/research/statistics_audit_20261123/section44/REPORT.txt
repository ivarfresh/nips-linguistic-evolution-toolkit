2. WHAT “ADJUSTING FOR THE ROUND-1 TRANSFER” MEANS (lines 95–97)

Each run supplies two numbers: mean chosen send in round 1 (one sender in a dyad,
four in a population), and mean chosen send over rounds 2–10. All agents are averaged
within that run. The run, not the individual decision, is the observation.

Let M=1 for myth→game and M=0 for game→myth. Fit separately to single-model runs,
mixed-model runs, then all runs:
  Before: later_send = composition×size intercept + b*M + error
  After:  later_send = composition×size intercept + b*M + c*round1_send + error
HC1 heteroskedasticity-robust standard errors; normal 95% intervals. No game-only
runs enter this comparison. All these runs have informed noise. This procedure does
not subtract round 1 from each decision; it adds the opening send as a predictor.

Subset       Runs  Before b (95% CI), raw p                  After b (95% CI), raw p
Single-model 60    .4162963 [.0618024,.7707902], .0213541     .1711803 [-.1374691,.4798298], .277029
Mixed-model  96    .4860359 [.2214372,.7506346], .000317951   .6588603 [.3145669,1.0031537], .000176339
All          156   .4592130 [.2475639,.6708621], .0000211384  .4859064 [.2425717,.7292411], .0000908617

All main-text values reproduce exactly before rounding, including the adjusted
single-model interval [-0.14,0.48]. There are six single-model and nine mixed-model
composition×size cells. The round-1 coefficient c is +.2000947 (p=.09898) in the
single-model subset, −.1063535 (p=.08802) in mixed runs and −.0181446 (p=.75580)
pooled. A single positive opening-carryover mechanism is therefore not established.

Limitations of interpretation:
- The before/after decrease itself was not tested. One coefficient being significant
  and the adjusted one not significant is not evidence that their difference is.
- Round-1 send is itself changed by task order: conditioning on it is a post-treatment
  adjustment, not a randomized intervention on openings or a causal mediation test.
- The adjustment imposes one linear opening slope within each fitted subset.
- HC1 treats runs as independent; it does not explicitly pair shared replicate/noise
  seeds across task orders. No Holm correction was used or claimed for these models.
- “single-model groups” is accurate; older README wording “single-model populations”
  is too narrow because both dyads and populations enter these 60 runs.

Recommended descriptive wording: “Adding each run's opening transfer to this
regression reduced the estimated single-model task-order difference from $0.42 to
$0.17 (95% CI −$0.14 to $0.48). This adjustment does not establish mediation through
the opening. The corresponding mixed-model estimate increased from $0.49 to $0.66.”

Source: analyses/myth_replay_analysis.py:72–92, also accurately described in Methods67.
Outputs: opening_adjustment_models.csv, opening_adjustment_runs.csv,
opening_adjustment_descriptives.csv (means and SDs).

3. LAG-ADJUSTED DYAD TASK-ORDER COEFFICIENTS (line 97; Table s-push)

One OLS model per model family:
  send_t = intercept + b1*game_myth + b2*myth_game
           + c*partner_last_shown_send + d*own_previous_send + error
Both lag variables are in dollars. Missing own previous sender turn removes rounds
1–2, leaving rounds 3–10. Game-only is the omitted task order. Mid-tier models pool
five runs per task order at each of three noise conditions, 45 runs/360 sender decisions
per model. Frontier models use five informed-noise runs per order, 15 runs/120 decisions.
The 2,000-draw bootstrap resamples matched (replicate,noise) blocks containing all three
task orders: 15 blocks for mid-tier and five for frontier. No noise predictor is fitted.
