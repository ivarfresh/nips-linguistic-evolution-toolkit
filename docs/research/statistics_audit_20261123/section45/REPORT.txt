Section 4.5 statistics audit — 2026-11-23

Scope and verdict

The main numerical claims reproduce from the stored myths, decisions, judge labels,
and cached embeddings. This is a numerical reproduction, not a validation of the LLM
judge's labels or proof of causal transmission. The important remaining issues are
which sample a claim describes, what the amount variable means, which hypotheses
belong to a correction family, and how much a null regression can establish.

1. Shown-versus-unseen word adoption — PASS

Source: analyses/linguistic_uptake.py:71–192 and 454–466.
Reruns: word_shown_unseen.csv; word_by_order.csv; word_independent.csv.

For each reader myth, the numerator counts distinct words present in the comparison
myth and the reader's new myth but absent from that reader's earlier OWN myths.
The denominator counts comparison-myth words absent from the reader's earlier own
myths. Words are lower-case content-word types, not token counts; they need not be
words the reader has never encountered in any previous received myth.

The unseen comparison is averaged across eligible same-family, same-round myths:
another agent in the same population run, or another matched run for dyads. Each
run's pairwise shares are averaged first; each run then receives equal weight.
The test is a two-sided Wilcoxon signed-rank test of the per-run difference. The
reported confidence intervals are t intervals for the mean difference, which is a
different estimand from the signed-rank test's symmetry/location null.

Thus 1.4–2.4 times and at least 96% reproduce after rounding. Exact minimum positive

The text's 1.2–1.3, 72–99%, and Holm p < 1e-4 all reproduce with its rounding.
The primary comparison has five-test Holm correction; additional exploratory
contrasts each have their own separate five-test correction, not a common 30-test
correction. Holm details are independently audited in the sibling audit.

A positive shown-minus-placebo difference supports exposure-specific word uptake.
The future myth is an observational negative control, not a randomized replacement
of the shown myth. Its author has read the reader's previous myth; it can share
words for that reason. Calling the difference a quantitatively identified causal
effect, or claiming that a CI strictly bounds all hidden transmission, needs extra
assumptions. This does not alter the arithmetic or the strong lexical pattern.

Reruns: classifier.csv; distance_curves.csv; distance_change.csv;

Round-1 family classification, five GroupKFold folds split by run: 836/840 myths
correct for EACH task order (150 runs each), accuracy .9952380952. Thus 99.5% is
correct. It is a per-myth accuracy on held-out runs, not 99.5% of runs classified
correctly. The binomial p in the source treats myths as independent; it is not the

5. Read amount to reader's send — PASS, variable needs clearer description

Source: docs/research/frontier_myth_predictors_20260930/plan/common.py:40–218;
plan/analyze.py:215–246. Rerun: amount_models.csv.

Sample: September first-five-replicate corpus, 8-agent myth→game only,
1,080 complete investor decisions in 45 runs; shown author differs from current
partner. Model in dollars:

send ~ shown_judge_amount + unseen_judge_amount + lag_sent
       + own_prev_judge_amount + b_coop_prev + c_coop_prev + C(runround)

lag_sent is the agent's previous own send; b_coop_prev is the shown author's
cooperation in their last game together; c_coop_prev is the current partner's
previous-round cooperation. Fixed effects are run × round; errors cluster by run.

Coefficient −.0002448429, t(44) CI [−.0985221476,.0980324618], p=.99601655.
The printed −$0.00 and [−.10,.10] reproduce. This supports 'no detectable
association under this model', not absence of any reader effect or equivalence.

IMPORTANT VARIABLE DEFINITION: judge_amount is the named amount if present,
otherwise a midpoint assigned to the judged rule: none=0, little=1.25,
moderate=2.75, most=4.25, all=5. It includes narrated amounts and band-imputed
amounts, not only explicitly endorsed/recommended numbers. The same definition
is used in the +$0.07 writing analysis below. Methods should disclose it.
Suggested wording: 'We scored the amount a myth describes using its named amount
when available; otherwise we assigned the judged send rule a value of 0, 1.25,
2.75, 4.25 or 5 for none, little, moderate, most or all. In populations where the
author was not the reader's current partner, this score had no detectable
association with the reader's next send (slope −0.0002, 95% CI −0.099 to 0.098).'
For the writing analysis: 'The reader's amount score was 0.074 points higher per
point of the shown myth's score (unadjusted 95% CI 0.030 to 0.117); this exploratory
association was sensitive to the choice of multiple-testing family.'

9. Read amount to next written amount — PASS, exploratory and correction-sensitive

Original: docs/research/myth_predictors_20260930/amount/analyze.py:185–196,
Holm families at 424–448. Rebuilt independently via current plan/common.py.
2,564 complete myths, 45 first-five-replicate 8-agent myth→game runs.
Outcome and predictor both use named-else-band-midpoint judge_amount.
Controls: unseen amount, own previous myth amount, own preceding cooperation,
shown author's last cooperation, and run × round fixed effects; errors cluster
by run. Coefficient .0738869510; original normal CI [.0302741360,.1174997661],
raw p=.0008986071. The printed +.07 [.03,.12] reproduces.

Stored Holm p values depend on family: .0179721421 across 25 explicitly selected
'primary' tests, .0557136406 within 62 R3 tests, .1428785300 across 178 finite
tests. Do not say simply 'survives Holm' or 'fails Holm'; name the family.
The audit does not establish that the 25-test selection was pre-registered.

Inference sensitivity, not an automatic bug correction: the original absorbed-FE
fit omits the absorbed FE count from the covariance small-sample factor. This is
a defensible convention when FE are nested within clusters (as run × round is
within run), documented by reghdfe. With the same covariance and t(44) inference,
the writing interval is [.0290413038,.1187325982], p=.0018131064. A full-dummy
statsmodels fit with its larger parameter-count correction plus t(44) gives
[.0250634276,.1227104745], p=.0038677972. Both reproduce the coefficient exactly.
The analogous read-to-send sensitivity CI is [−.120191389,.119701703], p=.996736.
These comparisons should be disclosed as inference conventions, not silently
substituted or used to select a favorable result.

Primary documentation: https://scorreia.com/software/reghdfe/faq.html (nested
fixed effects are not penalized twice), and
https://www.statsmodels.org/stable/generated/statsmodels.stats.sandwich_covariance.cov_cluster.html
(small-sample correction is enabled by default). These sources explain the
conventions; the numeric comparisons above are this audit's actual reruns.

Reproducibility and code delivery

reproduce.py contains every call performed in this specialist audit. Run its
word, moral, markers, regression, map, amount and descriptive modes from the repo
root. It reads the cached scientific inputs, never calls a judge or model.
comparison_checks.json records eight whole-table comparisons with stored output;
all pass. Audit CSVs retain full precision, standard deviations for descriptive
means, sample counts and confidence intervals.

source_code.tsv lists the primary code and direct supporting pipeline files.
Some original historical lens programs use hard-coded historical worktree paths;
the audit wrapper uses the current repo inputs instead. This is an execution
path repair in the audit only. Existing analysis scripts, input data, manuscript,
project memory and researchlog were not modified by this specialist.
