1. What Holm does here
---------------------
Sort the m raw p-values from smallest to largest. Multiply the first by m,
the second by m−1, and so on; take cumulative maxima, cap at 1, and restore
the original order. These are adjusted p-values. It is not just p multiplied
by the number of tests, and it is not the Benjamini–Hochberg/FDR procedure.
The functions in linguistic_uptake.py and myth_replay_analysis.py both
implement this correctly. 350 randomized/edge cases per implementation also
passed, including zeros, ones, tied p-values, and shuffled order; the uptake
function additionally passed missing-value cases. Missing/non-estimable
tests are excluded from the saved families, as their source code specifies.

The 95% intervals in these results are ordinary pointwise intervals, not
simultaneous Holm-adjusted intervals. The interval and adjusted-p decision can
therefore differ without an arithmetic error.

3. Moral matching: printed p-values are UNCORRECTED
-------------------------------------------------
The paper prints raw Wilcoxon p-values here, correctly reproduced:
  Shown−unseen, same family:  p=0.0153694 (printed 0.015).
  Shown−unseen, other family: p=0.1251056 (printed 0.13).
  Shown−placebo, same family: p=0.5433895 (printed 0.54).
  Shown−placebo, other family:p=0.6676683 (printed 0.67).
All are based on 60 mixed-population myth→game runs. The shown−unseen test
uses its full available pair set; the placebo contrast uses complete pairs.

The smallest natural family for the same/cross-family shown−unseen comparison
has two tests: p=0.0153694 becomes Holm p=0.0307387. Including the four
headline tests above makes it 0.0614774. Correcting the ten setting/order
shown−unseen rows of the existing full table makes it 0.0512650; correcting
all 40 tests of that table makes it 0.4610806. These are sensitivity families,
not claims about what was pre-registered. The full-table comparison has a
slightly different complete-pair restriction from the full-set headline.

Therefore the weak shown−unseen moral association must not be described as
robustly multiplicity-corrected. The scientific conclusion is still no clear
shown−placebo difference: neither of those raw tests is close to significance,
and correction only increases their p-values. Failure to reject does not
demonstrate an exactly zero causal effect.

4. The $0.07 reading-to-writing amount claim depends on test family
----------------------------------------------------------------
The exact saved coefficient is 0.073886951, interval [0.030274136,0.117499766],
raw p=0.000898607, 2,564 observations from 45 runs. It concerns an extracted
amount measure that uses a named amount when present and a rule-band midpoint
otherwise; it is not restricted to literal numerals in the myth.

amount/tests.csv records three valid arithmetic corrections for this row:
  Selected primary family, 25 estimable tests: Holm p=0.01797214.
  R3 family, 62 estimable tests:              Holm p=0.05571365.
  All 178 estimable tests in the lens:       Holm p=0.14287852.
The file has 269 rows total; 91 lack an estimable p-value and are excluded.
Thus 'passes Holm' and 'fails Holm' each need a named family. The selected
primary list is explicit in analyze.py:434–448, but this audit finds no
separate dated evidence establishing that this selection preceded analysis.
The code and all results were committed together on 2026-09-30 (428fc92e3).

The section-specific audit also checked the underlying regression inference:
the original uses absorbed fixed effects with normal-reference clustered
inference. A cluster-t reference and full-dummy small-sample convention give
larger p-values. Fixed effects nested within run clusters need not count as
independent parameters in the small-sample correction, so the full-dummy
alternative is a sensitivity analysis, not an automatically definitive fix.
Our Holm verification above is conditional on the saved raw p-values.

6. Test assumptions and scope
----------------------------
The stored word p-values reproduce with scipy 1.16.2 defaults. Untied n=30
task-order cells use exact signed-rank probabilities; n=60/120 cells use
the asymptotic calculation. Moral contrasts have ties/zero differences and
use the asymptotic calculation. The placebo/moral code rounds run differences
to ten decimals before testing, avoiding artificial floating-point ties.
The original uptake code does not round, but none of its tested differences
has an exact zero or tied absolute rank in this corpus.

Wilcoxon tests a symmetric distribution of paired differences around zero;
it is not itself a confidence test for the arithmetic mean shown by a bar.
The figure intervals use a t interval for the run mean, while moral intervals
use a run bootstrap. Report this distinction without claiming inconsistency.
Heterogeneous cells and skewed differences motivate caution about the signed-
rank assumptions. The audit exports sign-test and exact-distribution checks
as sensitivities, not substitutions selected for a preferred result.

In dyads, the unseen-myth baseline uses other runs from the same cell, so the
constructed run differences share baseline inputs. Raw signed-rank inference
does not explicitly model that dependence. In populations the baseline is
within-run, and shown−placebo contrasts are within-run at both sizes. This
supports the manuscript's decision to base transmission claims on populations.
Holm handles dependence among hypothesis tests; it cannot repair invalid raw
p-values or establish causal reading effects by itself.
