Feature screen v1 — frozen before paid pilot labels, 2026-10-03

User authorized a simpler screen, fresh calibration, then scaling only features
that pass. No rule-evolution counts, transmission attribution, or new experiments.
Model stays GPT-6.1 Sol, high reasoning. Direct model access was verified read-only.
Pilot: 36 myths from 36 runs not used in the prior 48-case audit or 24-case
calibration; 24 cohort/order cases (both orders where available; the range-2
bridge has myth-first only) and 12 lexical challenge candidates. Lexical matching
selects challenges only; it does not determine semantic labels. No prevalence
claim from this deliberately enriched sample. See selection.json for exclusions.

Measure isolated text features only. Distinguish absent/unclear/present, narrated
event/advice/custom/scenario, and endorsed/rejected/unclear stance. Group features
sharing one exact quotation to reduce repeated output. The source-first review
in source_review.json was written before seeing API labels and includes negatives.
It is an AI-assisted reference, not human ground truth or an independent human
reliability study. No reference label is silently changed to match API output.

Pilot batches contain six unrelated myths. Success gates, fixed before calls:
- All pilot ids and feature statuses covered; all quoted spans exact; finish=stop.
- Category has at least three definite positive and three definite negative
  source-review cases. Otherwise support is insufficient, not failure or absence.
- On definite reference cases, positive precision and sensitivity each >=0.85;
  an unclear model prediction does not count as successful positive detection.
- Three-state agreement including reference ambiguity >=0.85.
- Source adjudication finds no repeated material error in form/stance or meaning.

These are pragmatic gates for exploratory screening, not statistical proof of
accuracy. Tiny category samples imply wide uncertainty. Passing supports machine-
coded descriptive screening only; population claims still require human checks.
Any rubric change gets a separate version and fresh holdout; never tune and test
on this same set while calling it fresh validation.

Cost: resolved preflight before paid calls; pilot cap $10. Measure actual usage
before full pass. Prefer direct Batch if justified by quality, account access,
and turnaround. No expensive full run begins without the applicable cost approval.
Full summaries must keep cohorts, task orders, model families and scripted-defector
authors distinct. Failed labels are missing, not absent. Use whole runs for any
resampling. No behavioral or causal interpretation follows from text presence.
